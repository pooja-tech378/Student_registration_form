# 🎓 Student Registration Form

A simple and clean **Student Registration Form** created using **HTML5 and CSS3**.

This project is designed to practice HTML form elements and basic frontend styling.

## 📌 Project Overview

The Student Registration Form allows users to enter basic student and family details through a structured web form.

The form contains fields for:

* 👤 Student Name
* 🏫 Department
* 🔢 Register Number
* 📧 Mail ID
* 📱 Phone Number
* 👨 Father Name
* 👩 Mother Name
* 🎫 Roll Number
* 🏠 Address

## 🛠️ Technologies Used

* **HTML5** – For creating the structure and form elements.
* **CSS3** – For styling and designing the form.

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/student-registration-form.git
```

2. Open the project folder.

3. Open `index.html` in any web browser.

## 🖥️ Sample HTML

```html
<form>

    <label>Name</label>
    <input type="text" placeholder="Enter your name" required>

    <label>Department</label>
    <input type="text" placeholder="Enter your department" required>

    <label>Register Number</label>
    <input type="text" placeholder="Enter register number" required>

    <label>Mail ID</label>
    <input type="email" placeholder="Enter your mail ID" required>

    <label>Phone Number</label>
    <input type="tel" placeholder="Enter your phone number" required>

    <button type="submit">Register</button>

</form>
```
